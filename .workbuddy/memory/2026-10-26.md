## Cluster 阴影"无阴影"根因定位与修复
- 症状：数据链路全通（位置探针 GPU vs CPU 误差 0、全画旁路 SetData 成功、args 合法），但阴影图集全空、零报错；近处偶尔一个影子 + 移动波动。
- 根因：`Shadows.cs` 里 cluster 绘制用的 `worldToClip` 是裸 `proj*view`。自定义 HLSLPROGRAM 经 `DrawProceduralIndirect` 画阴影时**不走 `SetViewProjectionMatrices`**，后者内部会对投影矩阵套 `GL.GetGPUProjectionMatrix`（把 OpenGL 风格 [-1,1] z 换成平台 [0,1]/reversed-Z）。少了这一步 ⇒ D3D 上 NDC z 大量越界被裁光。
- 修复：`Matrix4x4 gpuProj = GL.GetGPUProjectionMatrix(m_cascadeProj[i], true); worldToClip = gpuProj * m_cascadeView[i];`（Shadows.cs:546 附近）。采样侧 `ConvertToAtlasMatrix(proj*view)` 已用 `usesReversedZBuffer` 做等价 z 取反，两侧深度约定一致。
- 编译：compile_check.py 零错误零警告。
- 待用户复测：保持 `clusterShadowForceAll=true`（旁路）先确认出阴影 ⇒ 出则关 forceAll 验 GPU 剔除。
