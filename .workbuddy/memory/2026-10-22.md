## Cluster 阴影 indirect draw 报错修复
- 现象：`CommandBuffer.DrawProceduralIndirect: GraphicsBuffer argument is missing IndirectArguments flag at creation time`（每级联一次，整帧刷屏）。
- 根因：`ClusterShadowRenderer.Rebuild()` 里 `argsBuf` 创建用了 `ComputeBufferType.Default`，但 `DrawProceduralIndirect` 要求参数 buffer 带 `IndirectArguments` 标志。
- 修复：`argsBuf = new ComputeBuffer(maxC*4, 4, ComputeBufferType.IndirectArguments);`
- 确认：该管线是**真·indirect draw**。`BuildArgs` kernel 写 `_Args[k*4+1]=_Counter[k]`（GPU 剔除出的可见簇数），`Draw()` 用 `DrawProceduralIndirect(argsBuf, 16*k)`，shader 用 `instanceID` 取 `_Visible[_ClusterBase+instanceID]` 得真实簇号。画哪些/画多少全由 GPU 决定。
